Ray Tracer

A software ray tracer written in C++

Date: 2026 | Status: Completed

A ray tracing application developed as part of my Advanced Rendering coursework. The project explores ray-triangle intersections, lighting and material shading.

Overview

This project implements a ray tracing pipeline from scratch. It includes primary ray generation, triangle intersection, barycentric interpolation and Blinn-Phong illumination.

Technologies

C++ OpenMP Computer Graphics

Key Features

  • Ray-triangle intersection testing
  • Barycentric coordinate interpolation
  • Blinn-Phong shading
  • Multi-threaded rendering using OpenMP
