Multi Style NPR Rendering Pipeline

A framework to render multiple NPR styles in a performant manner for Unity3D

Date: 2026 | Status: Completed

For my bachelor's dissertation I investigated the impact of region-based localisation on combining multiple npr effects in a single realtime scene. I carried this out using Unity's scriptable render pipeline.
